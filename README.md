Entry for [The 3 AM Excuse](https://make.fun/c/u-hazel-walrus-38-4764-the-3-am-excuse-c1017878) — one line, under 200 characters, in the voice of a hardware wallet refusing to sign a transaction at 3 AM.

The wallet is the only one keeping score: it kept every receipt, and the owner's last three 3 AM signatures all became 9 AM apologies. So it closes its screen like a shop for the night and tells the owner to come back when the sun — and their judgment — are up. No battery, firmware, or cold-storage joke; the hour itself is the evidence.

## Run

```sh
node main.ts
```

This writes the entry to `/output/entry.txt` (or to `$OUTPUT_PATH` if set), after a self-check that it is a single line of 1–200 characters.
